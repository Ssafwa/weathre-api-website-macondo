# 🌤️ Weather App

A simple and clean weather app built with HTML, CSS, and JavaScript.  
Search any city in the world and get live weather data instantly.

## ✨ Features
- Search weather by city name
- Shows live temperature, humidity, and wind speed
- Dynamic weather icons based on conditions (Rain, Clouds, Clear, Drizzle, Mist)
- Clean and responsive UI

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- [OpenWeatherMap API](https://openweathermap.org/api)
